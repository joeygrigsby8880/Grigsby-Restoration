# Grigsby Restoration

A lightweight, responsive marketing website for Grigsby Restoration. It uses plain HTML, CSS, and JavaScript and can be served from any static web host.

## Run locally

Open `index.html` in a browser, or serve the project directory with any local static file server.

## Customize

- Replace the sample Unsplash photos in `index.html` and `app.js` with Grigsby Restoration's own project photography before publishing. The gallery labels the current imagery as samples.
- The gallery upload tab previews before-and-after pairs in the current browser session only. Permanent uploads require a hosting service or backend.
- The estimator is a planning aid, not a quote or live AI service. It uses editable per-square-foot labor allowances in `app.js`, a fixed material allowance of $1.80 per square foot, and a 15% range around the subtotal. Mold remediation includes a $450 setup allowance. Confirm final scope and pricing with an on-site assessment.
- Update contact information and service details in `index.html`.
